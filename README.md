# Desafio-DIO-Criando-Um-Organizador-de-Declara-o-de-Imposto-de-Renda
Criando Um Organizador de Declaração de Imposto de Renda Projeto do Curso de Excel DIO

### Descrição da Atividade

Neste projeto, desenvolvi uma ferramenta em Excel para organizar informações utilizadas na declaração de Imposto de Renda, reunindo dados do titular, informes de rendimentos bancários e registros de entradas financeiras.

A planilha foi estruturada em diferentes abas para facilitar a organização das informações. Na aba **TITULAR**, são reunidos os dados pessoais necessários para o preenchimento. A aba **INFORMES** permite registrar os bancos, os valores atuais e os respectivos anexos dos informes de rendimentos. Na aba **NOTAS**, são registrados os valores de entrada mês a mês, juntamente com a data e a categoria da renda. A aba **BANCOS** funciona como uma base de apoio para os nomes das instituições financeiras.

Também implementei um campo de **Situação** na área de informes bancários, permitindo identificar se determinada informação está **OK, Informada ou precisa ser verificada**. Para facilitar o controle das pendências, utilizei a função **CONT.SE**, contabilizando automaticamente os registros marcados como “Verificar”.

Durante o desenvolvimento, apliquei conceitos de organização de dados, fórmulas, validação e automação no Excel, buscando tornar o preenchimento mais simples e facilitar a conferência das informações antes da declaração.

O projeto foi desenvolvido como uma aplicação prática dos conteúdos estudados nas aulas, utilizando o Excel para transformar dados organizados em uma ferramenta de controle mais funcional e estruturada.
